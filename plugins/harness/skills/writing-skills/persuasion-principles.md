# skill の設計と説得の原則

## 概要

LLM は人と同じ説得の原則に反応する。この心理を知っておくと、効く skill を設計しやすくなる。
目的は操作ではなく、圧力の下でも重要な手順が守られるようにすること。

**研究の土台:** Meincke et al. (2025) は 7 つの説得の原則を、AI との 28,000 件の会話で試した。
説得の技法で、従う率は 2 倍を超えた (33% → 72%、p < .001)。この研究が測ったのは不適切な依頼に従う率で、
ここでは同じ傾向が skill の手順を守らせる側にも働くとみなして使う。

## 7 つの原則

### 1. 権威

**何か:** 専門性、資格、公式の情報源に従う傾向。

**skill の中での働き:**

- 命令の言い回し: 「必ず〜しなければならない」「決して」「常に」
- 交渉の余地を残さない書き方: 「例外なし」
- 判断の疲れと言い訳を取り除く

**使う場面:**

- 規律を課す skill (TDD、検証の要件)
- 安全に関わる手順
- 確立したベストプラクティス

**例:**

```markdown
✅ テストより先にコードを書いた? 消す。最初からやり直す。例外なし。
❌ できるときはテストを先に書くことを検討する。
```

### 2. 一貫性

**何か:** 以前の行動、発言、公の宣言と一貫していたい傾向。

**skill の中での働き:**

- 宣言を求める: 「skill を使うと宣言する」
- 明示的な選択を迫る: 「A、B、C から選ぶ」
- 追跡を使う: チェックリストを todo にする

**使う場面:**

- skill が実際に守られるようにしたいとき
- 複数の段階を持つ手順
- 説明責任の仕組み

**例:**

```markdown
✅ skill を見つけたら、「[skill 名] を使う」と必ず宣言する。
❌ どの skill を使っているかを相手に伝えることを検討する。
```

### 3. 希少性

**何か:** 時間の制限や手に入りにくさから来る切迫感。

**skill の中での働き:**

- 時点を区切った要件: 「先へ進む前に」
- 順序の依存: 「X の直後に」
- 先延ばしを防ぐ

**使う場面:**

- その場で確かめる要件
- 時間に敏感な手順
- 「後でやる」を防ぎたいとき

**例:**

```markdown
✅ タスクを終えたら、先へ進む前に直ちにコードレビューを依頼する。
❌ 都合のよいときにコードをレビューしてよい。
```

### 4. 社会的証明

**何か:** 他の人がしていること、普通とされることに合わせる傾向。

**skill の中での働き:**

- 普遍の型: 「毎回」「常に」
- 失敗の型: 「Y の無い X = 失敗」
- 規範を作る

**使う場面:**

- 普遍的なやり方を書くとき
- よくある失敗を警告するとき
- 基準を強めるとき

**例:**

```markdown
✅ todo で追わないチェックリスト = 段階が飛ばされる。毎回。
❌ チェックリストに todo を使うと便利だと感じる人もいる。
```

### 5. 一体感

**何か:** 共有するアイデンティティ、「私たち」の感覚、内集団への帰属。

**skill の中での働き:**

- 協働の言い回し: 「私たちのコードベース」「私たちは同僚」
- 共有する目標: 「二人とも品質を求めている」

**使う場面:**

- 協働する手順
- チームの文化を作るとき
- 上下関係の無いやり方

**例:**

```markdown
✅ 私たちは一緒に働く同僚です。率直な技術的判断がほしい。
❌ 私が間違っていたら、たぶん言ったほうがいい。
```

### 6. 返報性

**何か:** 受けた恩恵を返さなければと感じる傾向。

**働き:**

- 控えめに使う。操作的に感じられうる
- skill で要ることはまれ

**避ける場面:**

- ほぼ常に (他の原則のほうが効く)

### 7. 好意

**何か:** 好ましく思う相手に協力したい傾向。

**働き:**

- **従わせるためには使わない**
- 率直なフィードバックの文化と衝突する
- 追従を生む

**避ける場面:**

- 規律を課すときは常に

## skill の種類ごとの組み合わせ

| skill の種類 | 使う | 避ける |
|------------|-----|-------|
| 規律を課す | 権威 + 一貫性 + 社会的証明 | 好意、返報性 |
| 指針・技法 | 控えめな権威 + 一体感 | 強い権威 |
| 協働 | 一体感 + 一貫性 | 権威、好意 |
| 参照 | 明確さだけ | 説得のすべて |

## 説得の原則が効く心理

明確な線を引いた規則は言い訳を減らす。

- 「必ず〜しなければならない」が判断の疲れを取り除く
- 絶対的な言い回しが「これは例外か?」という問いを消す
- 言い訳への明示的な反論が、特定の抜け道を塞ぐ

実行意図は自動的な振る舞いを作る。

- はっきりしたきっかけ + 求める行動 = 自動的な実行
- 「X のときは Y する」は「概して Y する」より効く
- 従うための認知の負荷を下げる

LLM は準人間的 (parahuman) になる。

- こうした型を含む人の文章で訓練されている
- 訓練データでは、権威の言い回しの後に従う行動が続く
- 一貫性の流れ (発言 → 行動) がよく現れる
- 社会的証明の型 (みんなが X する) が規範を作る

## 倫理的な使い方

**正当:**

- 重要な手順が守られるようにする
- 効く文書を作る
- 予測できる失敗を防ぐ

**不当:**

- 自分の利益のために操作する
- 偽の切迫感を作る
- 罪悪感で従わせる

**判定:** 利用者がその技法を完全に理解したうえでも、利用者の本当の利益に資するか。

## 研究の出典

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.

- 説得の 7 つの原則
- 影響力の研究の実証的な土台

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).**
Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.

- 7 つの原則を LLM との 28,000 件の会話で試した
- 説得の技法で従う率が 33% → 72% に上がった
- 権威、一貫性、希少性が最も効いた
- LLM の振る舞いの準人間モデルを裏づける

## 早見表

skill を設計するときは、次を問う。

1. **種類は何か** (規律、指針、参照のどれか)
2. **どの振る舞いを変えたいか**
3. **どの原則が当てはまるか** (規律ならたいてい権威 + 一貫性)
4. **組み合わせすぎていないか** (7 つ全部は使わない)
5. **倫理的か** (利用者の本当の利益に資するか)
