# 『組織の壁を越える』の背景

出典: 『組織の壁を越える』(英治出版, 2018) と、末尾の「出典」節に挙げた Web ページ。
同書の序章にあるアクティビティ「あなたのネクサス課題」を進めるための背景をまとめる。

ワーク中に「なぜこの問いを立てるのか」を説明したり、Step 4 の「なぜ?」で境界を
特定したり、Step 5 で読む章を選ぶときに参照する。

## このワークが序章に置かれている理由

CCL の調査では、経営層の 86% が「組織の壁を越えて仕事をすることがとても重要」と
答えた一方、「効果的に実践できている」は 7% にとどまった。重要性の認識と実践の間にある
この開きが出発点になっている。

ワークの狙いは、本書を「読んで終わり」にしないこと。自分の課題を1つ特定してから
読み進め、第4〜9章の実践と第10章のアクションを、その課題に結びつけて受け取れる
ようにする。書籍本文の言い方では、読み終わる頃には自分のチーム・部門・地域または
組織全体に応用できる短期・長期の具体的アクションが明らかになっている状態を目指す。

## 中核概念

**バウンダリー・スパニング・リーダーシップ**: より高いビジョンやゴールをめざし、
集団の境界を越えて方向性・団結力・責任感を築く能力。

**リーダーシップの3成果 (CCL の DAC モデル)**:

| 成果 | 内容 |
| ---- | ---- |
| ディレクション (方向性) | 目標や戦略に対する共通の理解 |
| アラインメント (団結力) | リソースや活動の組織的動員 |
| コミットメント (責任感) | 組織全体の成功に責任を負う姿勢 |

Step 2 の第1基準「境界を越える必要がある」は、表の成果を境界の向こう側の集団も
含めて築けるかを問うている。

**グレート・ディバイド**: 集団が「私たち」と「彼ら」に分裂したときに生じる、
破壊的かつ非生産的な事象。本質はアイデンティティの問題であり、組織図に描かれる
構造的な境界より、心理的・心情的な境界のほうが効く。

**ネクサス効果**: 各集団が一致協力して初めて到達できる、単独では実現できない
可能性や成果。ネクサス = 連結点・結節点。図I.2 の螺旋は、グレート・ディバイドから
ネクサス効果へ向かう上昇の道筋を表す。

## 5つの境界

Step 4 の「なぜ?」で、関係する境界と集団を特定するときに使う。

| 境界 | 何で隔てられるか | 例 |
| ---- | ---- | ---- |
| 垂直 | 階層、地位、年功、権限 | 経営層とミドル、管理者と現場、年配と若手 |
| 水平 | 機能、部門、専門性 | 営業と製造、開発と運用、事業部間 |
| ステークホルダー | 組織の内と外 | 自社と顧客、協力会社、パートナー企業 |
| 人口属性 | 性別、人種、学歴、世代、思想 | 男女間、中途と新卒、専門背景の違い |
| 地理 | 距離、場所、文化、市場 | 本社と拠点、国内と海外、合併後の異文化 |

実務上は垂直と水平が阻害要因になりやすいが、そこで止まらず5つ全部を当ててみる。
見落とされがちなステークホルダー境界や人口属性境界が本丸のことがある。

## 6つの実践と対応する章

Step 5 で「どの章から読むか」を決めるときに使う。3つのグループは下から積み上がる
順序になっており、境界のマネジメントができていない状態で共通の土台づくりに進んでも
効きにくい。

| グループ | 実践 | 境界への働きかけ | 生まれる成果 | 章 |
| ---- | ---- | ---- | ---- | ---- |
| 境界のマネジメント | バッファリング | 境界を明確にする | 安全・安心 | 第4章 |
| 境界のマネジメント | リフレクティング | 境界の向こうを映す | 敬意 | 第5章 |
| 共通の土台づくり | コネクティング | 境界を棚上げする | 信頼 | 第6章 |
| 共通の土台づくり | モビライジング | 境界を再構成する | コミュニティ | 第7章 |
| 新たなフロンティアの発見 | ウィービング | 境界を織り合わせる | 相互依存 | 第8章 |
| 新たなフロンティアの発見 | トランスフォーミング | 境界を切断する | 再構成・改革 | 第9章 |

第10章「ネクサス効果とあなた」で、自身の課題に結びつけた具体的アクションを起こす
ところまでを扱う。
